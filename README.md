# Desmos Synthesizer Song-Generator
A script/application that allows me to compose a song easily using a UI menu and paste the output into a Desmos Graphing Calculator synthesizer. The graph then plays the resulting song
## Sweden.txt
This repository also contains an output file which encodes the first few measures of "Sweden" by C418.
## The Graph
The Desmos graph can be found here: [https://www.desmos.com/calculator/rztutxbobm](url)
